# Skills — инструкции для агентов

- Репозиторий скиллов: `skills/<имя>/SKILL.md` + `scripts/`, `reference/`. Это канонические экземпляры:
  `~/.claude/skills/<имя>` и `.claude/skills/<имя>` проектов — junction'ы сюда, правки — только здесь.
- Репозиторий публичный (GitHub, MIT): не класть сюда секреты, внутренние адреса, токены, данные плат.
- Скрипты — только stdlib, если скилл не говорит иного; новый скилл — строка в таблице `README.md`.
- Коммитит владелец.
